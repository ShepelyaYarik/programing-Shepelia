**Загальне завдання:**
Розробити програму мовою C для роботи з динамічними масивами та матрицями, використовуючи виключно адресну арифметику (вказівники). Забезпечити покриття коду модульними тестами (Unit Tests), перевірку на витоки пам'яті та згенерувати документацію за допомогою Doxygen.

**Індивідуальне завдання:**

2.  Реалізувати отримання елементів головної діагоналі матриці в одновимірний масив.
3.  Відсортувати отриманий масив за зростанням (метод бульбашки).
4.  **Обмеження:**
    * Заборонено використовувати індексацію масивів (`[]`), тільки розіменування вказівників (`*`).
    * Заборонено використовувати `printf`/`scanf` в логіці програми (вхідні дані — константи, вихідні — через відлагодник).
    * Продемонструвати відсутність витоків пам'яті (Valgrind).
    * Покриття тестами не менше 50%.

**ОПИС ПРОГРАМИ**

**Функціональне призначення:**
Програма призначена для демонстрування навичок управління динамічною пам'яттю (`malloc`, `free`) та роботи з вказівниками на вказівники. Вона виконує виділення пам'яті під матрицю, вибірку даних та їх сортування без використання стандартної індексації.

**Опис логічної структури:**

### src/lib.c
Цей файл містить основну бізнес-логіку бібліотеки.

**Функції:**
* `int** create_matrix(size_t size)`
    * **Опис**: Виділяє пам'ять під масив вказівників та під кожен рядок матриці окремо. Реалізує захист від витоків пам'яті у разі помилки `malloc`.
    * **@param** size: Розмірність матриці.
    * **@return**: Вказівник на створену матрицю (int**) або NULL.

* `void free_matrix(int** matrix, size_t size)`
    * **Опис**: Звільняє пам'ять у зворотному порядку: спочатку звільняються всі рядки, потім масив вказівників.
    * **@param** matrix: Вказівник на матрицю.
    * **@param** size: Розмірність матриці.

* `void get_diagonal(int** matrix, size_t size, int* out_array)`
    * **Опис**: Копіює елементи головної діагоналі у вихідний масив. Використовує адресну арифметику `*(*(matrix + i) + i)` для доступу до елементів.
    * **@param** matrix: вхідна матриця.
    * **@param** size: розмірність.
    * **@param** out_array: буфер для результату.

* `void sort_array(int* array, size_t size)`
    * **Опис**: Сортує масив методом бульбашки. Порівняння та обмін елементів (swap) відбуваються через розіменування вказівників.
    * **@param** array: масив для сортування.
    * **@param** size: розмір масиву.

### test/test.c
Модуль для автоматичного тестування з використанням бібліотеки `check.h`.

**Тести:**
* `test_get_diagonal`
    * **Опис**: створює тестову матрицю 3x3, заповнює її даними та перевіряє, чи правильно функція витягує діагональні елементи.
* `test_sort_array`
    * **Опис**: передає у функцію невідсортований масив та перевіряє, чи відповідає результат очікуваному відсортованому порядку.

**Важливі фрагменти програми:**

1.  Доступ до елемента матриці через арифметику вказівників (аналог `matrix[i][i]`):

```c
int value = *(*(matrix + i) + i);
```
2. Обмін елементів (Swap):

```c
if (*(array + j) > *(array + j + 1)) {
    int temp = *(array + j);
    *(array + j) = *(array + j + 1);
    *(array + j + 1) = temp;
}
```
