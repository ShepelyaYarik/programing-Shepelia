**ОПИС ПРОГРАМИ**

**Функціональне призначення:**
Програма демонструє роботу з функціями, масивами та аргументами командного рядка в мові C. Вона генерує масив випадкових чисел, виводить його та розраховує суму елементів. Діапазон генерації можна налаштовувати під час запуску.

**Опис логічної структури:**

### main.c
Цей файл містить реалізацію програми.

**Макроси:**
* `#define SIZE 10`
    * Сталий розмір масиву, що використовується у програмі.

**Функції:**
* `int myfunction(int list[SIZE])`
    * **Опис**: Обчислює суму елементів масиву. Функція проходить по всім елементам масиву та додає їх. Також виводить розраховану суму в консоль.
    * @param list: Вхідний масив цілих чисел.
    * **@return**: Загальна сума елементів масиву (int).

* `void randgen(long min, long max, int number[SIZE])`
    * **Опис:** Заповнює масив випадковими числами. Генерує цілі числа в діапазоні [min, max] (включно) та записує їх у наданий масив.
    * @param min: Нижня межа діапазону (включно).
    * @param max: Верхня межа діапазону (включно).
    * @param number[out]: Масив, який буде заповнено випадковими числами.

* `void print(int number[SIZE])`
    * **Опис:** Виводить вміст масиву в консоль. Друкує кожен елемент масиву разом з його індексом.
    * @param number: Масив, елементи якого потрібно надрукувати.

* `int main(int argc, char *argv[])`
    * **Опис**: Головна функція програми. Ініціалізує генератор випадкових чисел. Обробляє аргументи командного рядка (argc, argv) для встановлення `min` та `max` значень. Послідовно викликає `randgen()`, `print()` та `myfunction()`.
    * @param argc: Кількість аргументів командного рядка.
    * @param argv: Масив рядків (аргументи командного рядка).
    * @return: 0 у разі успішного виконання, 1 у разі помилки.
