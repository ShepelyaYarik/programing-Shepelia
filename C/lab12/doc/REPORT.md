---

**ВИМОГИ**

**Розробник:** студент Шепеля Ярослав, група КН-925а

**Загальне завдання:** розробити програму мовою C, яка зчитує багаторядковий текст (до EOF) та обробляє його згідно з варіантом. для зберігання даних використовувати динамічний масив. доступ до елементів масивів здійснювати виключно через розіменування покажчиків (без індексації []). перевірити програму на витоки пам'яті та покрити модульними тестами (не менше 50%).

**Індивідуальне завдання:** частотна таблиця символів (варіант 21).

---

**ОПИС ПРОГРАМИ**

**Функціональне призначення:** програма конвеєрно зчитує введений текст по рядках, накопичує частоту появи кожного символу (включаючи службові) у динамічному масиві. після отримання сигналу кінця файлу (Ctrl+D) програма виводить таблицю з відсотковим співвідношенням частоти кожного символу.

**Опис логічної структури:** цей файл містить структуру модулів.

### src/lib.c
цей файл містить основну математичну логіку.

**Функції:** перелік розроблених методів:
* void calc_frequency(const char *str, int *freq, int *total_chars)
    * опис: виконує підрахунок та накопичення частоти символів у заданому рядку.
    * @param str: покажчик на вхідний рядок.
    * @param freq: покажчик на динамічний масив-лічильник (розміром 256).
    * @param total_chars: покажчик на змінну-накопичувач загальної кількості символів.

### test/test.c
модуль для автоматичного тестування з використанням бібліотеки check.h.

**Тести:** перелік тестових сценаріїв:
* test_calc_frequency_normal
    * опис: перевіряє правильність підрахунку частоти символів на базовому слові.
* test_calc_frequency_empty
    * опис: перевіряє обробку порожнього рядка.

**Важливі фрагменти програми:** нижче наведено ключові моменти коду:

1. доступ до масиву лічильників виключно через адресну арифметику:
(*(freq + (unsigned char)*str))++;

2. конвеєрне зчитування багаторядкового тексту до сигналу EOF:
while (fgets(buffer, sizeof(buffer), stdin) != NULL) {
    calc_frequency(buffer, freq, &total_chars);
}
