**ОПИС ПРОГРАМИ**

**Функціональне призначення:** програма ініціалізує динамічний масив (список) для зберігання структур мобільних телефонів. Вона дозволяє динамічно додавати нові елементи (з автоматичним розширенням пам'яті за допомогою `realloc`), видаляти елементи за індексом зі зсувом масиву, сортувати пристрої за кількістю оперативної пам'яті та підраховувати загальний обсяг RAM.

**Опис логічної структури:** проект розділено на сутності (опис структури) та логіку списку (динамічного масиву).

### src/entity.c / src/entity.h
Ці файли містять опис самої структури `MobilePhone` (базові поля, `enum` для ОС та типу, `union` для специфічних полів спадкоємців) та функцію для виводу інформації про один телефон (`print_single_phone`).

### src/list.c / src/list.h
Цей модуль містить структуру `PhoneList` (динамічний масив) та всі методи для управління ним.

**Функції:** перелік розроблених методів:

* `void list_init(PhoneList *list)`
  * опис: ініціалізує список, встановлюючи початкову місткість та виділяючи стартовий блок пам'яті через `malloc`.

* `void list_add(PhoneList *list, const MobilePhone *phone)`
  * опис: додає новий об'єкт у кінець списку. Якщо поточна кількість елементів перевищує місткість, пам'ять автоматично розширюється вдвічі за допомогою `realloc`.

* `void list_remove_at(PhoneList *list, size_t index)`
  * опис: видаляє елемент за вказаним індексом. Всі елементи, що знаходяться праворуч від видаленого, зсуваються на одну позицію вліво за допомогою арифметики вказівників.

* `void list_sort_by_ram(PhoneList *list)`
  * опис: виконує сортування елементів масиву (наприклад, алгоритмом бульбашки) за полем `ram_mb`.

* `long list_calculate_total_ram(const PhoneList *list)`
  * опис: реалізація цільової функції з категорії «Методи для роботи з колекцією». Підраховує загальний об'єм RAM у масиві.

* `void list_free(PhoneList *list)`
  * опис: звільняє виділену під динамічний масив пам'ять.

### test/test.c
Модуль для автоматичного тестування логіки динамічного масиву, написаний з використанням фреймворку **Check**.

**Тести:** перелік тестових сценаріїв:
* `test_list_add_and_count`: перевіряє початкову ініціалізацію та додавання елемента (чи правильно збільшується `count` та зберігаються дані).
* `test_list_remove`: перевіряє видалення елемента та коректність зсуву наступних елементів вліво.
* `test_list_calculate_ram`: перевіряє математичну точність підрахунку сумарного об'єму оперативної пам'яті.
* `test_list_sort`: перевіряє правильність сортування елементів списку за зростанням об'єму RAM.

**Важливі фрагменти програми:** нижче наведено ключові моменти коду:

1. Структура динамічного масиву:

```c
typedef struct {
    MobilePhone *items; // Вказівник на динамічний масив
    size_t count;       // Поточна кількість елементів
    size_t capacity;    // Місткість виділеної пам'яті
} PhoneList;

```

2. Динамічне розширення пам'яті та додавання елемента (через розіменування вказівника):

```c
if (list->count >= list->capacity) {
    list->capacity *= 2;
    MobilePhone *new_items = (MobilePhone *)realloc(list->items, list->capacity * sizeof(MobilePhone));
    if (!new_items) exit(EXIT_FAILURE);
    list->items = new_items;
}
*(list->items + list->count) = *phone;
list->count++;

```

3. Зсув масиву при видаленні елемента виключно через арифметику вказівників:

```c
for (size_t i = index; i < list->count - 1; i++) {
    *(list->items + i) = *(list->items + i + 1);
}
list->count--;

```
