# Лабораторна робота №11
## Тема: взаємодія з користувачем шляхом механізму введення/виведення

---

**ВИМОГИ**

**Розробник:** студент Шепеля Ярослав, група КН-925а

**Загальне завдання:** розробити програму мовою C, яка взаємодіє з користувачем через стандартні потоки введення/виведення (`scanf`, `printf`). забезпечити валідацію вхідних даних (діапазон від -1000 до 1000). доступ до елементів масивів здійснювати виключно через розіменування покажчиків. перевірити програму на витоки пам'яті та покрити модульними тестами (не менше 50%).

**Індивідуальне завдання:** визначити зворотню матрицю (варіант 5).

---

**ОПИС ПРОГРАМИ**

**Функціональне призначення:** програма зчитує розмірність та елементи квадратної матриці, перевіряє їх на відповідність заданому діапазону та обчислює зворотню матрицю за допомогою методу Гауса-Жордана.

**Опис логічної структури:** цей файл містить структуру модулів.

### src/lib.c
цей файл містить основну математичну логіку.

**Функції:** перелік розроблених методів:
* `int invert_matrix(float *mat, float *inv, int n)`
    * **опис:** виконує обчислення зворотньої матриці.
    * **@param mat:** покажчик на вхідну матрицю.
    * **@param inv:** покажчик на матрицю, куди записується результат.
    * **@param n:** розмірність матриці.
    * **@return:** 0 у разі успіху, 1 якщо матриця вироджена.

### test/test.c
модуль для автоматичного тестування з використанням бібліотеки `check.h`.

**Тести:** перелік тестових сценаріїв:
* `test_invert_matrix_normal`
    * **опис:** перевіряє правильність обчислення зворотньої матриці на коректних даних (матриця 2х2).
* `test_invert_matrix_singular`
    * **опис:** перевіряє обробку виродженої матриці (визначник дорівнює нулю), очікується повернення коду помилки.

**Важливі фрагменти програми:** нижче наведено ключові моменти коду:

1. доступ до елементів матриці виключно через розіменування покажчиків:
```c
*(mat + i * n + j) = temp;
```

2. валідація вхідних даних за вимогами бізнес-логіки:
```c
if (temp <= -1000.0f || temp >= 1000.0f) {
    printf("Помилка: число %.3f виходить за межі діапазону.\n", temp);
    return 1;
}
```
