**ОПИС ПРОГРАМИ**

**Функціональне призначення:** програма приймає шлях до цільового каталогу через аргументи командного рядка, рекурсивно обчислює його загальний об'єм у байтах та записує відформатований результат у вказаний вихідний файл з дотриманням спеціальних правил форматування розмірності.

**Опис логічної структури:** цей файл містить структуру модулів.

### src/lib.c
цей файл містить основну логіку обходу дерева каталогів та форматування виводу.

**Функції:** перелік розроблених методів:
* unsigned long long get_dir_size(const char *dir_path)
    * опис: обчислює загальний розмір каталогу рекурсивно, ігноруючи системні посилання.
    * @param dir_path: шлях до цільового каталогу.
    * @return: загальний розмір каталогу у байтах.
* void write_formatted_size(FILE *file, unsigned long long size)
    * опис: форматує загальний розмір згідно з вимогами та записує у файл.
    * @param file: вказівник на відкритий файл для запису.
    * @param size: обчислений розмір у байтах.

### test/test.c
модуль для автоматичного тестування з використанням бібліотеки check.h.

**Тести:** перелік тестових сценаріїв:
* test_write_formatted_size
    * опис: перевіряє правильність форматування розміру та запису різних граничних значень у тимчасовий файл.
* test_get_dir_size
    * опис: перевіряє обчислення об'єму для неіснуючого каталогу та каталогу з тимчасовими тестовими файлами.

**Важливі фрагменти програми:** нижче наведено ключові моменти коду:

1. рекурсивний обхід каталогу та ігнорування системних посилань:
```c
if (strcmp(entry->d_name, ".") == 0 || strcmp(entry->d_name, "..") == 0) {
    continue;
}
```

2. отримання розміру файлу через lstat та безпечне приведення типів:
```c
if (S_ISDIR(statbuf.st_mode)) {
    total_size += get_dir_size(path);
} else {
    total_size += (unsigned long long)statbuf.st_size;
}
```

3. форматування розміру з жорстким діленням на 1000:
```c
while (formatted_size >= 1000.0 && unit_index < 5) {
    formatted_size /= 1000.0;
    unit_index++;
}
```
