**ОПИС ПРОГРАМИ**

**Функціональне призначення:** програма приймає шлях до вхідного файлу через командний рядок, динамічно виділяє пам'ять та зчитує масив даних про мобільні телефони. за допомогою перерахувань (enum) та об'єднань (union) програма розрізняє типи телефонів (спадкоємців) та виконує цільові запити для обчислення пам'яті і фільтрації специфічних пристроїв.

**Опис логічної структури:** цей файл містить структуру модулів.

### src/lib.c

цей файл містить основну логіку роботи зі структурами, читання з файлу та методи обробки колекції.

**Функції:** перелік розроблених методів:

* void read_from_file(const char *filepath, MobilePhone phones, int *count)
* опис: читає дані з файлу, динамічно виділяє пам'ять для масиву структур та заповнює специфічні поля залежно від типу телефону.
* @param filepath: шлях до текстового файлу з даними.
* @param phones: подвійний вказівник на масив структур для запису результату.
* @param count: вказівник на змінну для збереження кількості елементів.


* void print_phones(MobilePhone *phones, int count)
* опис: виводить базову інформацію про всі телефони у масиві на екран.
* @param phones: вказівник на масив структур.
* @param count: кількість елементів.


* long calculate_total_ram(MobilePhone *phones, int count)
* опис: ітерується по масиву та обчислює сумарний об'єм оперативної пам'яті всіх пристроїв.
* @param phones: вказівник на масив структур.
* @param count: кількість елементів.
* @return: загальний об'єм RAM у байтах/мегабайтах.


* void find_non_grandma_push_phones(MobilePhone *phones, int count)
* опис: знаходить та виводить на екран кнопкові телефони, поле is_grandma_phone яких дорівнює нулю.


* void find_foldable_phones(MobilePhone *phones, int count)
* опис: фільтрує колекцію та виводить інформацію виключно про складані телефони (звертаючись до полів відповідного об'єднання).



### test/test.c

модуль для автоматичного тестування логіки та методів обробки масиву структур.

**Тести:** перелік тестових сценаріїв:

* test_read_and_print
* опис: створює тимчасовий текстовий файл, перевіряє правильність динамічного зчитування масиву структур та покриває функцію виводу на екран.


* test_calculate_total_ram
* опис: перевіряє математичну коректність підрахунку сумарного об'єму оперативної пам'яті на жорстко заданому масиві.


* test_find_functions
* опис: перевіряє логіку доступу до специфічних полів union та правильність роботи умов if під час пошуку спадкоємців різних типів.

**Важливі фрагменти програми:** нижче наведено ключові моменти коду:

1. імітація спадкування за допомогою об'єднань (union) та перерахувань (enum):
typedef struct {
// ... базові поля ...
PhoneType type;
union {
PushButtonData push_button;
FoldableData foldable;
} specific;
} MobilePhone;
2. динамічне виділення пам'яті через подвійний вказівник з безпечним приведенням типів:
*phones = (MobilePhone *)malloc((size_t)(*count) * sizeof(MobilePhone));
if (!*phones) {
perror("Помилка виділення пам'яті");
exit(EXIT_FAILURE);
}
3. доступ до елементів масиву виключно через арифметику вказівників (без квадратних дужок):
if ((*phones + i)->type == TYPE_PUSH_BUTTON) {
fscanf(file, "%d %d",
&((*phones + i)->specific.push_button.is_grandma_phone),
&((*phones + i)->specific.push_button.button_count));
}
