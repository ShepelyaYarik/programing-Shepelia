# Лабораторна робота №17. Об'єктно-орієнтоване програмування. Вступ до ООП

**Виконав:** студент Шепеля Ярослав Миколайович  
**Група:** КН-925а  

## Загальне завдання

На базі заданої предметної галузі (варіант 18 — "Мобільний телефон") розробити клас сутності та клас-колекцію з дотриманням базових принципів ООП (інкапсуляція, управління життєвим циклом об'єктів).

Реалізувати наступний функціонал:
* Створення класу `Phone`, що відображає сутність пристрою.
* Усі поля мають бути приватними (інкапсуляція), доступ до них — через публічні гетери та сетери.
* Реалізація трьох типів конструкторів (за замовчуванням, з аргументами через списки ініціалізації, копіювання) та деструктора з логіюючими повідомленнями у консоль.
* Створення класу-колекції `List`, що інкапсулює динамічний масив покажчиків на об'єкти та самостійно керує виділенням/звільненням пам'яті (запобігання витокам).
* Реалізація методів роботи з колекцією: додавання об'єкта (із можливістю вставки за індексом), видалення об'єкта за індексом, отримання елемента за індексом та вивід усіх елементів на екран.
* Реалізація індивідуального методу обходу колекції: розрахувати загальний об'єм оперативної пам'яті всіх телефонів у списку.

## Опис прикладної області

* **Клас сутності (`Phone`):**
  * Чи є водостійким (тип `bool`)
  * Чи є ударостійким (тип `bool`)
  * Модель або повна назва (тип `std::string`)
  * Кількість оперативної пам'яті, Мб (тип `int`)
  * Розмір сховища, Мб (тип `int`)
  * Розмір екрану (структура `ScreenSize`, що містить ширину та висоту екрану у пікселях)
  * Операційна система (перелік `enum class OperatingSystem`: Android, iOS, Symbian, WindowsPhone)

* **Клас-колекція (`List`):**
  * Інкапсулює динамічний масив покажчиків `Phone** data` для оптимізації роботи з пам'яттю та швидкодії.
  * Зберігає поточну кількість елементів у полі `size_t size`.

## Структура проекту

* `src/entity.h` / `src/entity.cpp` — опис класу `Phone`, його конструкторів, гетерів, сетерів та методу виводу.
* `src/list.h` / `src/list.cpp` — опис та реалізація класу-колекції `List` з керуванням динамічною пам'яттю та методом обходу (підрахунок RAM).
* `src/main.cpp` — головний файл програми, точка входу з демонстрацією життєвого циклу об'єктів.
* `test/test.cpp` — модульні тести (Google Test) для повної перевірки логіки сутності, колекції та обробки помилок.
* `Makefile` — скрипт для збірки (C++17), автоматичного тестування та перевірки покриття.

## Інструкція з компіляції та запуску

* `make run` — компіляція та запуск програми / тестів.
* Запуск демонстрації вручну: `./dist/main.bin`
* Запуск тестів вручну: `./dist/test.bin`
