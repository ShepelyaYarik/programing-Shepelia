**ОПИС ПРОГРАМИ**

**Функціональне призначення:** програма розширює можливості моделювання предметної області «Мобільний телефон» за допомогою перевантаження стандартних операторів C++. Вона дозволяє порівнювати об'єкти телефонів між собою за їхніми технічними характеристиками, виконувати безпечне глибоке копіювання об'єктів через оператор присвоювання, а також використовувати звичний синтаксис масивів `list[i]` для зчитування чи модифікації елементів колекції. Завдяки перевантаженню операторів `<<` та `>>`, операції консольного та файлового вводу/виводу для сутностей та всього контейнера стали інтуїтивно зрозумілими й інтегрованими в систему стандартних потоків C++.

**Опис логічної структури:** проект базується на архітектурі попередньої роботи, але повністю переорієнтований на операторний синтаксис.

### src/entity.cpp / src/entity.h

У клас `Phone` додано перевантаження таких операторів:

* `Phone& operator=(const Phone& other)` — оператор присвоювання. Виконує пооб'єктне копіювання всіх полів з обов'язковою перевіркою на самоприсвоювання (`this != &other`).
* `bool operator==(const Phone& other) const` та `bool operator!=(const Phone& other) const` — оператори порівняння. Рівність визначається збігом моделі, об'єму пам'яті та встановленої ОС. Оператор `!=` реалізовано через логічне заперечення результату оператора `==`.
* `friend std::ostream& operator<<(std::ostream& os, const Phone& phone)` та `friend std::istream& operator>>(std::istream& is, Phone& phone)` — дружні оператори потоків. Дозволяють виводити об'єкт у потік та зчитувати його (десеріалізувати рядок) за допомогою методів `toString()` та `fromString()`.

### src/list.cpp / src/list.h

У клас-контейнер `List` інтегровано такі оператори:

* `Phone& operator[](size_t index)` та `const Phone& operator[](size_t index) const` — константна та неконстантна версії оператора індексування. Замінюють старі методи доступу. Надають пряме посилання на об'єкт `Phone` у динамічному масиві з обов'язковою генерацією виключення `std::out_of_range` у разі виходу за допустимі межі списку.
* `friend std::ostream& operator<<(std::ostream& os, const List& list)` та `friend std::istream& operator>>(std::istream& is, List& list)` — оператори потоків для всього контейнера. Дають змогу записати весь список у файл або консоль одним виразом `stream << list` або повністю відновити динамічну колекцію з файлу через `stream >> list`.

### test/test.cpp

Модуль для автоматичного тестування перевантажених операторів, написаний з використанням **Google Test Framework**.

**Тести:** перелік нових тестових сценаріїв:

* `PhoneOperatorTest.AssignmentAndComparison`: перевіряє коректність роботи оператора присвоювання (`=`) та логіку операторів рівності (`==`) і нерівності (`!=`).
* `PhoneOperatorTest.StreamOperators`: перевіряє роботу операторів `<<` та `>>` для сутності `Phone` за допомогою тимчасового буфера `std::stringstream`.
* `ListOperatorTest.IndexingOperator`: перевіряє роботу `operator[]` як у режимі читання полів, так і в режимі модифікації об'єкта всередині списку, а також генерацію виключень при помилковому індексі.
* `ListOperatorTest.ListStreamOperators`: перевіряє наскрізне зчитування та запис усього класу-списку через перевантажені оператори потоків.

**Важливі фрагменти програми:** нижче наведено ключові моменти коду з реалізацією операторів:

1. Перевантаження операторів присвоювання та еквівалентності для сутності:

```cpp
Phone& Phone::operator=(const Phone& other) {
    if (this != &other) {
        isWaterproof = other.isWaterproof;
        isShockproof = other.isShockproof;
        model = other.model;
        ramMb = other.ramMb;
        storageMb = other.storageMb;
        screenSize = other.screenSize;
        os = other.os;
    }
    return *this;
}

bool Phone::operator==(const Phone& other) const {
    return (model == other.model && ramMb == other.ramMb && storageMb == other.storageMb && os == other.os);
}

```

2. Реалізація оператора індексування `[]` для контейнера `List`:

```cpp
Phone& List::operator[](size_t index) {
    if (index >= size) {
        throw std::out_of_range("Індекс виходить за межі масиву");
    }
    return *data[index];
}

const Phone& List::operator[](size_t index) const {
    if (index >= size) {
        throw std::out_of_range("Індекс виходить за межі масиву");
    }
    return *data[index];
}

```

3. Дружні оператори потоків для автоматизації взаємодії класу `List` з файлами:

```cpp
std::ostream& operator<<(std::ostream& os, const List& list) {
    for (size_t i = 0; i < list.size; ++i) {
        os << *(list.data[i]) << "\n";
    }
    return os;
}

std::istream& operator>>(std::istream& is, List& list) {
    list.clear();
    std::string line;
    while (std::getline(is, line)) {
        if (line.empty()) continue;
        Phone tempPhone;
        tempPhone.fromString(line);
        list.addPhone(tempPhone, list.size);
    }
    return is;
}

```

Під час виконання лабораторної роботи №19 я успішно опанував механізм перевантаження операторів у мові C++, що є одним із ключових інструментів створення інтуїтивно зрозумілих інтерфейсів класів.

Я реалізував оператор присвоювання з глибоким копіюванням полів та захистом від самоприсвоювання, а також оператори порівняння (`==` та `!=`), що дозволило порівнювати екземпляри сутності `Phone` за логічними критеріями, а не за їхніми адресами в пам'яті. Перевантаження оператора індексування `[]` для класу-контейнера `List` значно спростило синтаксис взаємодії з елементами динамічного масиву, зробивши роботу з об'єктом схожою на стандартні контейнери STL.

Тепер операції виводу даних на екран або у файл виконуються за допомогою уніфікованих і лаконічних виразів.
