## Загальне завдання

Поширити попередню лабораторну роботу (варіант 18 — "Мобільний телефон") шляхом переходу на стандартні потоки C++ та додавання функціоналу роботи з файлами. 

Реалізувати наступний функціонал:
* Заміна C-функцій вводу/виводу (`printf`/`scanf`) на використання потоків `cin`/`cout`.
* Заміна всіх конкатенацій рядків на використання класу `std::stringstream`.
* Заміна методу виводу інформації на метод серіалізації, що повертає рядок-інформацію про об'єкт (`std::string toString() const`).
* Заміна методу вводу на метод десеріалізації, що приймає рядок з інформацією, обробляє його та заповнює поля об'єкта (`void fromString(const std::string& data)`).
* Поширення класу-списку методами роботи з файлами за допомогою файлових потоків (`<fstream>`):
  1. `void readFromFile(std::string& fileName)` — зчитування колекції з файлу (з попереднім очищенням списку).
  2. `void writeToFile(std::string& fileName)` — запис колекції у текстовий файл.
* Повна відмова від використання C-бібліотек для рядків (`char*`).
* Заборона використання глобального простору імен (`using namespace std;`), замість цього використовуються точкові виклики (наприклад, `using std::string`, `using std::cout`).

## Опис прикладної області (Ієрархія класів)

Предметна область залишилася незмінною, але тепер класи підтримують серіалізацію у текстовий формат, де поля розділені символом `|`.

* **Базовий клас (`MobilePhone`):**
  * Водостійкість (bool)
  * Ударостійкість (bool)
  * Модель (std::string)
  * Об'єм RAM, Мб (int)
  * Розмір сховища, Мб (int)
  * Розмір екрану (структура `ScreenSize`)
  * Операційна система (перелік `enum class OS`)

* **Спадкоємець 1 — Кнопковий телефон (`ButtonPhone`). Додаткові поля:**
  * Чи є бабусяфоном (bool)
  * Кількість кнопок (int)

* **Спадкоємець 2 — Складаний телефон (`FoldablePhone`). Додаткові поля:**
  * Чи складається телефон навпіл (bool)
  * Розмір екрану у складеному стані (структура `ScreenSize`)

* **Клас-колекція (`PhoneList`):**
  * Керує динамічним масивом вказівників на `MobilePhone`.
  * Реалізує специфічні методи підрахунку RAM та пошуку пристроїв через `dynamic_cast`.
  * Здійснює запис та зчитування поліморфної колекції з текстового файлу.

## Структура проекту

* `src/entity.h` / `src/entity.cpp` — опис ієрархії класів, перевантажених методів `toString()` та `fromString()`.
* `src/list.h` / `src/list.cpp` — опис та реалізація колекції `PhoneList`, управління пам'яттю та файловими потоками (`fstream`).
* `src/main.cpp` — головний файл програми (демонстрація запису у файл `phones.txt` та читання з нього).
* `test/test.cpp` — модульні тести (Google Test) для перевірки парсингу рядків та роботи з файлами.
* `Makefile` — скрипт для збірки, тестування, перевірки покриття та генерації документації.

## Інструкція з компіляції та запуску

* `make run` — компіляція та запуск основної програми (згенерує файл `phones.txt`).
* `make test` — збірка та запуск модульних тестів (Google Test), а також генерація звіту про покриття коду (через `llvm-cov`).
* `make valgrind` (або `make leak-check`) — перевірка програми на витоки пам'яті.
* `make doxygen` (або `make format`) — генерація документації.
