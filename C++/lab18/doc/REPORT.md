**ОПИС ПРОГРАМИ**

**Функціональне призначення:** програма моделює предметну область «Мобільний телефон» з використанням парадигми ООП та стандартної бібліотеки потоків C++. Вона дозволяє створювати динамічну колекцію телефонів, перетворювати їх у текстовий формат (серіалізація за допомогою `stringstream`) із використанням вертикальної риски `|` як розділювача та зберігати у файл (за допомогою `ofstream`). Програма також вміє зчитувати дані з текстового файлу (`ifstream`), коректно очищувати пам'ять перед новим завантаженням та відновлювати об'єкти (десеріалізація).

**Опис логічної структури:** проект базується на класі сутності та класі-контейнері з повністю переробленою системою вводу/виводу.

### src/entity.cpp / src/entity.h

Файли містять оголошення та реалізацію базових компонентів:
* `ScreenSize` — допоміжна структура, що описує фізичні розміри екрану в пікселях (ширина та висота).
* `OperatingSystem` — перелік (`enum class`) доступних операційних систем (Android, iOS, Symbian, Windows Phone).
* `Phone` — основний клас сутності. Містить поля: `isWaterproof`, `isShockproof`, `model`, `ramMb`, `storageMb`, `screenSize` та `os`. Реалізує методи `toString()` та `fromString()` для текстової обробки даних пристрою.

### src/list.cpp / src/list.h

Цей модуль містить клас `List`, що інкапсулює логіку роботи з динамічним масивом покажчиків на об'єкти `Phone`, а також методи файлового вводу/виводу.

**Функції (Методи класу `List`):**
* `void readFromFile(const std::string& fileName)`
  * опис: відкриває файл за допомогою `std::ifstream`. Перед читанням обов'язково викликає метод очищення списку `clear()` для запобігання витокам пам'яті. Порядково зчитує файл, створює тимчасовий об'єкт `Phone`, викликає його метод `fromString()` та додає до колекції.
* `void writeToFile(const std::string& fileName)`
  * опис: відкриває файл за допомогою `std::ofstream`. Проходить по всіх елементах масиву, викликає метод `toString()` для кожного об'єкта і записує отримані рядки у файл, розділяючи їх символом нового рядка.
* `void clear()`
  * опис: приватний допоміжний метод. Послідовно звільняє виділену в купі пам'ять під кожен окремий об'єкт `Phone`, після чого очищує сам масив покажчиків та обнуляє лічильник `size`.

### test/test.cpp

Модуль для автоматичного тестування логіки класів, написаний з використанням **Google Test Framework**.

**Тести:** перелік тестових сценаріїв:
* `PhoneTest.GettersAndConstructors`: перевіряє роботу конструкторів та точність повернення значень гетерами.
* `PhoneTest.Setters`: перевіряє коректність зміни полів через сетери та роботу конвертації ОС у рядок.
* `PhoneStreamTest.SerializationWithVerticalBar`: перевіряє точність серіалізації/десеріалізації через `stringstream` з використанням розділювача `|`.
* `ListStreamTest.FileReadWriteAndClear`: перевіряє запис колекції у текстовий файл, її відновлення (читання) та обов'язкове очищення пам'яті контейнера при повторному зчитуванні.
* `ListStreamTest.MissingFileThrowsException`: перевіряє генерацію виключення `std::runtime_error` при спробі відкрити неіснуючий файл.

**Важливі фрагменти програми:** нижче наведено ключові моменти коду:

1. Використання `std::stringstream` для перетворення об'єкта в рядок (серіалізація через `|`):

```cpp
std::string Phone::toString() const {
    std::stringstream ss;
    ss << model << "|"
       << isWaterproof << "|"
       << isShockproof << "|"
       << ramMb << "|"
       << storageMb << "|"
       << screenSize.width << "|"
       << screenSize.height << "|"
       << static_cast<int>(os);
    return ss.str();
}

```

2. Робота з файловими потоками (`std::ofstream`) для збереження колекції:

```cpp
void List::writeToFile(const string& fileName) {
    ofstream file(fileName);
    if (!file.is_open()) {
        throw std::runtime_error("Не вдалося відкрити файл для запису: " + fileName);
    }

    for (size_t i = 0; i < size; ++i) {
        file << data[i]->toString() << "\n";
    }
    file.close();
}

```

3. Парсинг рядка (`std::getline`) з розділювачем у вигляді вертикальної риски:

```cpp
void Phone::fromString(const string& data) {
    if (data.empty()) return;
    
    stringstream ss(data);
    string tempStr;
    
    std::getline(ss, model, '|');
    std::getline(ss, tempStr, '|'); isWaterproof = (tempStr == "1");
    std::getline(ss, tempStr, '|'); isShockproof = (tempStr == "1");
    std::getline(ss, tempStr, '|'); ramMb = std::stoi(tempStr);
    std::getline(ss, tempStr, '|'); storageMb = std::stoi(tempStr);
    std::getline(ss, tempStr, '|'); screenSize.width = std::stoi(tempStr);
    std::getline(ss, tempStr, '|'); screenSize.height = std::stoi(tempStr);
    std::getline(ss, tempStr, '|'); os = static_cast<OperatingSystem>(std::stoi(tempStr));
}

```

**ВИСНОВКИ**

Під час виконання лабораторної роботи №18 я успішно закріпив навички використання стандартної бібліотеки потоків C++. Я повністю відмовився від застарілих процедурних C-функцій (`printf`, `scanf`) та роботи з "сирими" вказівниками на символи (`char*`) на користь сучасних та безпечних рішень (`std::cin`, `std::cout`, `std::string`).

Я навчився використовувати клас `std::stringstream` для зручного форматування та парсингу текстових даних за визначеним делімітером (вертикальна риска `|`). Завдяки цьому було реалізовано надійний механізм серіалізації (`toString()`) та десеріалізації (`fromString()`) об'єктів.

Головним досягненням роботи стала реалізація довготривалого зберігання даних за допомогою класів файлових потоків `std::ifstream` та `std::ofstream`. Тепер програма здатна стабільно зберігати стан колекції об'єктів у текстовий файл на диску та повністю відновлювати його під час наступного запуску, автоматично очищуючи попередню пам'ять контейнера для уникнення витоків. Також я дотримався кращих практик програмування, уникаючи глобального імпорту просторів імен (`using namespace std;`). Код відповідає вимогам якості, покритий модульними тестами на понад 50% і не містить витоків пам'яті, що підтверджено утилітою Valgrind.
