**ОПИС ПРОГРАМИ**

**Функціональне призначення:** програма демонструє практичне застосування узагальненого програмування (Generic Programming) за допомогою шаблонів мови C++. Створено універсальний, незалежний від типу даних контейнер `List` (динамічний масив), що підтримує керування пам'яттю, автоматичне перевиділення простору під час додавання елементів, а також базові алгоритми пошуку, сортування та фільтрації для будь-яких типів даних, які задовольняють вимогам операторів порівняння та виведення у потік.

**Опис логічної структури:** архітектура проєкту враховує головну особливість шаблонів у C++: оскільки компілятору необхідно бачити визначення шаблонного класу під час його інстанціації, весь код (оголошення класу та реалізація його методів) винесено у заголовочний файл `src/list.hpp`.

### src/list.hpp
Універсальний шаблонний клас `List<T>`. Оперує приватними полями:
* `T* data` — вказівник на динамічний масив типу `T`.
* `size_t capacity` — загальна місткість виділеної пам'яті.
* `size_t size` — фактична кількість елементів у списку.

Клас реалізує повний життєвий цикл керування пам'яттю:
* Конструктор за замовчуванням ініціалізує порожній список.
* Деструктор гарантовано звільняє виділену динамічну пам'ять за допомогою оператора `delete[] data` для запобігання витокам пам'яті.
* Приватний метод `resize()` автоматично збільшує місткість масиву вдвічі при досягненні ліміту.

Реалізовані методи інтерфейсу:
* `void append(const T& element)` — додавання елемента в кінець із контролем місткості.
* `void print() const` — послідовне виведення елементів у потік `std::cout`.
* `int indexOf(const T& element) const` — лінійний пошук елемента, повертає індекс або `-1`.
* `T min() const` — пошук мінімального елемента. Викидає виняток `std::out_of_range`, якщо список порожній.
* `void sort()` — сортування елементів методом «бульбашки». Використовує перевантажені оператори порівняння `>` для типу `T`.
* `void removeAt(size_t index)` — видалення елемента за індексом зі зміщенням лівої частини масиву.

### src/main.cpp
Точка входу в програму. Демонструє роботу розробленого шаблону на прикладі двох кардинально різних типів даних:
1. `List<int>` — робота з примітивними числовими типами даних (додавання, видалення, пошук мінімуму, сортування чисел).
2. `List<std::string>` — робота зі складними об'єктами стандартної бібліотеки (сортування за алфавітом, пошук текстових рядків).

### test/test.cpp
Файл модульного тестування. Замість важких зовнішніх бібліотек, реалізовано власну ефективну систему тестів на базі макросу `ASSERT`. Це дозволяє утиліті `llvm-cov` коректно збирати метрики покриття для шаблонів у заголовочних файлах. Тести повністю покривають:
* Додавання елементів та динамічне розширення масиву.
* Правильність роботи методів сортування та знаходження мінімуму для `int` та `std::string`.
* Контроль генерації виняткових ситуацій (`std::out_of_range`) при некоректному доступі до індексів порожнього контейнера.

**Важливі фрагменти програми:**

1. Оголошення шаблонного класу та методів автоматичного керування пам'яттю в `list.hpp`:

```cpp
template <typename T>
class List {
private:
    T* data;          
    size_t capacity;  
    size_t size;      

    void resize() {
        capacity = (capacity == 0) ? 1 : capacity * 2;
        T* newData = new T[capacity];
        for (size_t i = 0; i < size; ++i) {
            newData[i] = data[i];
        }
        delete[] data;
        data = newData;
    }
public:
    List() : data(nullptr), capacity(0), size(0) {}
    ~List() { delete[] data; }
    
    // ... інші методи
};

```

2. Реалізація методів пошуку мінімального та сортування з узагальненими типами:

```cpp
T min() const {
    if (size == 0) {
        throw out_of_range("List is empty");
    }
    T minVal = data[0];
    for (size_t i = 1; i < size; ++i) {
        if (data[i] < minVal) {
            minVal = data[i];
        }
    }
    return minVal;
}

void sort() {
    if (size < 2) return;
    for (size_t i = 0; i < size - 1; ++i) {
        for (size_t j = 0; j < size - i - 1; ++j) {
            if (data[j] > data[j + 1]) {
                T temp = data[j];
                data[j] = data[j + 1];
                data[j + 1] = temp;
            }
        }
    }
}

```
