## Загальне завдання

Розробити універсальний шаблонний клас-контейнер для зберігання та обробки елементів довільного типу на базі динамічного масиву:
* **Створити шаблонний клас-список `List<T>`**, що має шаблоноване поле масиву для роботи з будь-яким існуючим типом даних.
* **Реалізувати автоматичне керування пам'яттю** (динамічне розширення місткості вдвічі при досягненні ліміту, гарантоване звільнення пам'яті в деструкторі).
* **Створити обов'язкові методи інтерфейсу:**
  * Виведення вмісту масиву на екран (`print`).
  * Визначення індексу переданого елемента в масиві (`indexOf`).
  * Сортування елементів масиву методом бульбашки (`sort`).
  * Визначення значення мінімального елемента масиву (`min`).
  * Додавання елемента до кінця масиву (`append`).
  * Видалення елемента з масиву за вказаним індексом (`removeAt`).
* **Дотриматись обмежень проєкту:** не використовувати конструкцію `using namespace std;`, відмовитися від бібліотек введення/виведення мови C, не використовувати рядки типу `char*`.
