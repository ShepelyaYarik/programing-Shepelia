**ОПИС ПРОГРАМИ**

**Функціональне призначення:** програма демонструє практичне застосування парадигм наслідування та динамічного поліморфізму для моделювання предметної області розширеної ієрархії мобільних пристроїв. Вона забезпечує керування різнотипними об'єктами (`SmartPhone`, `ButtonPhone`, `FoldingPhone`) всередині єдиного гетерогенного контейнера `List` через вказівники на абстрактний базовий клас `Phone`. Реалізовано обчислювальні та фільтраційні алгоритми з використанням динамічного приведення типів (`dynamic_cast`), глибоке копіювання поліморфних об'єктів (патерн *Prototype*) та уніфіковану серіалізацію/десеріалізацію даних із збереженням маркерів фактичних типів.

**Опис логічної структури:** архітектуру проєкту повністю перебудовано для підтримки чистого поліморфізму (класи рознесено за принципами SOLID).

### src/entity.h / src/entity.cpp

* `Phone` — **абстрактний базовий клас**. Його деструктор зроблено віртуальним (`virtual ~Phone()`), що є критично важливим для запобігання витокам пам'яті під час видалення об'єктів спадкоємців через базові вказівники. Клас містить суто віртуальні (абстрактні) методи:
  * `virtual std::string getType() const = 0;` — повертає текстову назву типу пристрою.
  * `virtual Phone* clone() const = 0;` — патерн «Прототип», забезпечує поліморфне глибоке копіювання об'єктів без знання їхнього реального типу на етапі компіляції.
* Методи серіалізації `toString()` та `fromString()` оголошені як `virtual` для реалізації поліморфного введення/виведення.
* `SmartPhone` — конкретний клас-спадкоємець, що уособлює стандартний моноблочний телефон без додаткових полів (наприклад, Google Pixel 8). Дозволяє повноцінно протестувати інтерфейс базового класу. Застосовує специфікатори `override` та `final`.
* `ButtonPhone` — клас-спадкоємець. Поширює функціонал базового класу полями `isGrandpaPhone` та `buttonCount`. Застосовує специфікатор `override` для перевизначених віртуальних методів.
* `FoldingPhone` — кінцевий клас-спадкоємець. Додає специфічні поля структури `foldedScreenSize` та прапорець `isFoldInHalf`. Використовує ключове слово `final` разом із `override` для заборони подальшого успадкування.

### src/list.h / src/list.cpp

Клас `List` тепер оперує єдиним динамічним масивом вказівників на базовий клас `Phone** data`, що дозволяє зберігати будь-яких спадкоємців в одній структурі.
* Реалізовано конструктор копіювання та оператор присвоювання для `List` (згідно з *Rule of Three*), які використовують метод `->clone()` для створення точних глибоких копій об'єктів у динамічній пам'яті.
* Інтегровано 3 індивідуальні методи варіанта:
  * `int getTotalRam() const` — обходить масив і підсумовує RAM.
  * `List getNonGrandpaButtonPhones() const` — фільтрує елементи за допомогою `dynamic_cast<ButtonPhone*>`, відсіюючи ті, де прапорець бабусяфона встановлено в `true`.
  * `List getFoldingPhones() const` — виокремлює з масиву об'єкти типу `FoldingPhone` за допомогою `dynamic_cast`.

**Поліморфний ввід/вивід:** дружній оператор `operator>>` для класу `List` зчитує рядки з текстового файлу, аналізує початковий маркер-ідентифікатор (`SMART`, `BUTTON` або `FOLDING`), динамічно виділяє пам'ять через `new` під відповідний клас-спадкоємець, після чого викликає віртуальний метод `fromString()` для відновлення внутрішнього стану об'єкта.

**Важливі фрагменти програми:**

1. Абстрактні та віртуальні методи в `entity.h` з використанням модифікаторів:

```cpp
class Phone {
    // ... пооб'єктні базові поля
public:
    virtual ~Phone(); // Віртуальний деструктор
    virtual std::string getType() const = 0; // Чисто віртуальний метод
    virtual Phone* clone() const = 0;        // Для глибокого копіювання
    virtual std::string toString() const;
    virtual void fromString(const std::string& data);
};

class SmartPhone final : public Phone {
public:
    virtual std::string getType() const override final;
    virtual Phone* clone() const override final;
};

class ButtonPhone : public Phone {
public:
    virtual std::string getType() const override;
    virtual Phone* clone() const override;
};

class FoldingPhone final : public Phone {
public:
    virtual std::string getType() const override final;
    virtual Phone* clone() const override final;
};

```

2. Реалізація індивідуального розрахункового методу з `dynamic_cast`:

```cpp
List List::getNonGrandpaButtonPhones() const {
    List result;
    for (size_t i = 0; i < size; ++i) {
        ButtonPhone* btnPhone = dynamic_cast<ButtonPhone*>(data[i]);
        if (btnPhone != nullptr) { // Перевірка, що об'єкт є саме ButtonPhone
            if (!btnPhone->getIsGrandpaPhone()) {
                result.addPhone(btnPhone->clone());
            }
        }
    }
    return result;
}

```

3. Логіка поліморфного зчитування списку з файлу (`operator>>` у `list.cpp`):

```cpp
std::istream& operator>>(std::istream& is, List& list) {
    list.clear();
    std::string line;
    while (std::getline(is, line)) {
        if (line.empty()) continue;
        
        size_t pos = line.find('|');
        if (pos == std::string::npos) continue;
        std::string marker = line.substr(0, pos);

        Phone* current = nullptr;
        if (marker == "BUTTON") {
            current = new ButtonPhone();
        } else if (marker == "FOLDING") {
            current = new FoldingPhone();
        } else if (marker == "SMART") {
            current = new SmartPhone();
        }

        if (current != nullptr) {
            current->fromString(line);
            list.addPhone(current, list.size); 
        }
    }
    return is;
}

```
